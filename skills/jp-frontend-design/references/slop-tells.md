# Slop tells: the paired list

Every NEVER carries an INSTEAD, because a ban alone relocates the default (Anthropic documented
its own ban on Inter producing Space Grotesk). Step 1 slop-tests directions against this list;
step 4's critic receives it verbatim. Tells marked [M] are mechanical: a grep or a computed-style
read catches them without a judge.

| Never | Instead |
|---|---|
| Inter/system font as the personality [M] | pick faces from the subject's world; system faces are fine when the REGISTER is operate and the choice is stated |
| purple-to-indigo gradient hero [M] | one flat ground from the palette stance; spend boldness in one place |
| three-card feature grid | one hero region with real hierarchy; cards only when items are genuinely parallel |
| untouched component-library defaults [M] | restyle through tokens before the first screen |
| emoji as UI icons [M] | a single icon set, or text labels; on operate surfaces prefer words |
| uniform rounded-shadow cards on everything [M] | one radius stance applied where elevation means something; flat by default |
| big-number-small-label hero stat | label beside value, units on every number, rounded values |
| cream + serif + terracotta "tasteful" default | if warm and editorial is right, earn it with subject-grounded materials, not this palette |
| near-black + single acid accent default | if dark and technical is right, vary the accent's job, not just its hue |
| broadsheet hairlines + zero-radius default | borrow editorial structure only when the register is read |
| centered-everything | top-left answers first; center only what is ceremonial |
| copy that sells instead of explains | name things by what the user controls; buttons say what happens |
| colored left border on cards [M] (2026) | status as shape + word + color inline with the content |
| badge row above the H1 (2026) | the H1 leads; metadata below in the muted role |
| icon-top card grids (2026) | text-first rows; icons only where they disambiguate |
| stat-row of four big numbers (2026) | one number that matters at glance size, the rest in a table |
| all-caps tracked labels everywhere [M] (2026) | tracked caps for section labels ONLY, +5 to 12% |
| italic-serif single hero word (2026) | if the display face has a voice, use it for the whole heading |
| glassmorphism glow / backdrop-blur chrome [M] (2026) | solid surfaces from the token pairs |
| `opacity: 0` at rest waiting for JS [M] (2026) | content visible without script; motion is enhancement |
| nested cards (card in card in card) (2026) | flatten; one container level per region |
| bounce/spring easing on utility UI [M] (2026) | one duration pair, one standard easing, honor reduced-motion |

## Faces that now read as AI defaults

Inter, Space Grotesk, Fraunces, Playfair Display, DM Sans, Plus Jakarta Sans, IBM Plex (as a
reflex), Outfit. None is banned as a face; each is banned as an UNCHOSEN default. Using one
requires the plan's type-character line to say why it belongs to this subject.

## The crowding test (the gate behind all of this)

Would a generic version of this prompt produce the same direction? Slop is a population
property: each output looks fine alone, the set converges. If the answer is yes, the direction
is replaced, and the replacement names what it does differently.
